## Что это

GasApp — мессенджер со сквозным шифрованием: переписка один на один и
каналы. Сервер хранит и передаёт шифротекст.

| Обещание | Как обеспечивается |
|---|---|
| Сервер никогда не видит содержимое переписки | Сквозное шифрование, сервер маршрутизирует непрозрачные блобы |
| Приватные ключи не покидают устройство | Аппаратное хранилище: Secure Enclave / StrongBox |
| Backup не расшифровывается сервером | Ключ восстановления существует только у пользователя |
| Нет восстановления через email или SMS | Почта нужна только чтобы создать аккаунт; вернуть аккаунт можно лишь ключом восстановления |
| Нет аналитики и рекламы | Ноль сторонних SDK, проверяется в CI |
| Защита от «записали сейчас — вскроем потом» | Пост-квантовый PQXDH: вся цепочка ключей выводится из гибридного секрета X25519 + ML-KEM-1024. ⚠️ Пост-квантовый храповик SPQR реализован в `gasapp-protocol`, но **в сессии не подключён**: восстановления после компрометации против квантового противника пока нет |
| Регистрация без номера телефона | Идентификатор — `@username`; аккаунт подтверждается кодом из письма |
| Сервер не хранит адрес почты | В базе — только HMAC адреса на ключе узла: хватает, чтобы не дать завести второй аккаунт на тот же адрес |
| Сервер не знает, кто читает канал | Записи забираются без подписи запроса. Подписчик для сервера — случайный жетон на один канал: по нему считаются просмотры и реакции, а чей он, в базе не записано |

## Регистрация: адрес почты

Чтобы создать аккаунт, нужен адрес почты: сервер присылает на него
шестизначный код (действует 15 минут, пять попыток ввода), и аккаунт
создаётся только с верным кодом. Один адрес — один аккаунт.

Что это меняет для приватности — прямо:

- сервер **видит** адрес в момент запроса кода, а **хранит** только его
  хеш (HMAC-SHA-256 на ключе `GASAPP_EMAIL_KEY`);
- оператор, у которого есть ключ, может проверить, зарегистрирован ли
  **известный ему** адрес;
- почтовая служба, через которую уходит письмо, видит адрес, время и код.
  Её журналы — вне сервера GasApp.

Адрес не участвует ни во входе, ни в восстановлении: потеряв устройство
и ключ восстановления, вернуть аккаунт по почте нельзя.

## Каналы и премиум

Канал — лента записей одного автора для многих читателей.

- **Создать** канал может только аккаунт с премиумом. Премиум выдаёт
  оператор сервера вручную: кнопкой в админ-центре или командой
  `gasapp-server-admin premium grant <имя>`. Оплаты в приложении нет.
- **Читать** канал может любой, у кого есть ссылка-приглашение
  (`gasapp://channel/…`) или её QR-код.
- **В записи** — текст, фото и файлы. Автор правит и удаляет записи,
  закрепляет одну, ставит каналу аватар. Читатели ставят реакции;
  у записей есть счётчик просмотров, у канала — подписчиков.
- Название, описание, записи и файлы сервер хранит **шифротекстом**:
  ключ чтения лежит в ссылке и на сервер не попадает. Каждая запись,
  правка и удаление подписаны автором — сервер их не подделает, не
  переставит и не откатит, но может не отдать.
- **Администраторы.** Владелец назначает администраторов по их заявке (QR-код): они
  публикуют, правят и удаляют записи своими ключами. Кому верить, читатели
  узнают из описания канала, а его подписывает только владелец — сервер
  администратора не назначит и снятого не вернёт.
- **Подписка стоит пропуска** — анонимного одноразового права, которое сервер
  выдаёт аккаунту вслепую (не больше сорока в сутки): подписчиков не накрутить
  циклом, а сервер не знает, чей пропуск потрачен.
- **Ключи каналов входят в резервную копию**: потеря телефона не отнимает канал.
- **Публичный канал.** Автор может дать каналу `@имя`, и его найдут
  поиском. ⚠️ Для этого серверу отдаётся ссылка, а с ней ключ чтения:
  публичный канал сервер прочитать может. Подделать — по-прежнему нет.

⚠️ Канал — не личная переписка. Ключ чтения один на всех и не меняется:
кто получил ссылку, читает весь канал, прошлое и будущее, и отозвать её
у одного читателя нельзя. Подпись автора — Ed25519, без пост-квантовой
половины. Подробности — `docs/protocol/GASAPP-PROTOCOL-v1.md`, раздел
«Каналы».

## Чего GasApp не делает

Честность о границах важнее маркетинга. GasApp **не защищает** от:

- вредоносного ПО с правами root или jailbreak на вашем устройстве;
- человека, стоящего у вас за спиной;
- собеседника, который решит переслать вашу переписку;
- принуждения выдать пароль;
- фотографирования экрана другим устройством.

GasApp **защищает** от: провайдера связи, оператора сервера, взлома сервера,
перехвата трафика, кражи выключенного устройства и от расшифровки записанного
сегодня трафика квантовым компьютером в будущем.

## Архитектура

```text
   Swift / SwiftUI              Kotlin / Compose
        (iOS)                       (Android)
          │                             │
          └──────────── UniFFI ─────────┘
                        │
              Rust Security Core
     identity · ratchets · storage · network
                        │
                   ciphertext
                        │
                 ┌──────────────┐
                 │    Сервер    │
                 │ zero-knowledge│
                 └──────────────┘
```

Криптографию выполняет только Rust-ядро. UI-слой физически не имеет
доступа к ключам: в публичном API нет ни одной функции, которая их возвращает.
