# Встроенные мосты Tor для GasApp — строка на мост.
#
# Используются, когда прямое подключение к сети Tor не удаётся
# (Tor заблокирован): приложение переключается на них само.
# Поддерживается WebTunnel (клиент — в ядре, без сторонних программ):
#
#   webtunnel [2001:db8::1]:443 ОТПЕЧАТОК url=https://домен/путь ver=0.0.1
#
# Мосты Tor Project здесь не нужны и не должны лежать: приложение само
# спрашивает свежие у moat (как Tor Browser) — каждый получает свои, а
# не одни на всех из APK, которые цензор прочёл бы первыми.
#
# Сюда — свои мосты проекта: поднимается за несколько минут,
# server/deploy/webtunnel (скрипт печатает готовую строку). Чем больше
# мостов на разных адресах и у разных хостеров, тем труднее
# заблокировать все сразу.
#
# ⚠️ Мосты из открытого репозитория блокировщики найдут первыми.
# Приватные — в отдельном файле: ./gradlew … -PgasappBridgesFile=путь.
