# Встроенные мосты Tor для AEGIS — строка на мост.
#
# Используются, когда прямое подключение к сети Tor не удаётся
# (Tor заблокирован): приложение переключается на них само.
# Поддерживается WebTunnel (клиент — в ядре, без сторонних программ):
#
#   webtunnel [2001:db8::1]:443 ОТПЕЧАТОК url=https://домен/путь ver=0.0.1
#
# Свой мост поднимается за несколько минут: server/deploy/webtunnel
# (скрипт печатает готовую строку). Чем больше мостов на разных
# адресах и у разных хостеров, тем труднее заблокировать все сразу.
#
# ⚠️ Мосты из открытого репозитория блокировщики найдут первыми.
# Приватные — в отдельном файле: ./gradlew … -PaegisBridgesFile=путь.
