# Snapshot-тесты — временно отключены от сборки

Каталог `debug-snapshot-tests/` содержит написанные, но **ни разу не
запускавшиеся** snapshot-тесты компонентов (`AegisButton`, `AegisTextField`,
`AegisListRow`).

## Почему они не в `src/debug`

Тесты используют Paparazzi, а он подключается **Gradle-плагином**
(`app.cash.paparazzi`), а не обычной зависимостью: Paparazzi рендерит вью
на JVM без эмулятора и для этого встраивается в конфигурацию сборки.

В `app/build.gradle` раньше стояла координата
`com.github.paparoni:paparazzi:1.3.1` — артефакта с таким именем не
существует (настоящий — `app.cash.paparazzi`). Ошибка прожила до сессии
2026-08-13 незамеченной ровно потому, что Gradle в этом проекте никогда
не запускался: корневой `build.gradle` содержал блок `android {}`, ронявший
любую задачу, а wrapper отсутствовал.

## Что нужно, чтобы их вернуть

1. Подключить плагин в корневом `build.gradle`:
   `id 'app.cash.paparazzi' version '1.3.5' apply false`, в `app` — `apply`.
2. Перенести каталог обратно в `app/src/debug`.
3. Сгенерировать эталонные изображения: `./gradlew recordPaparazziDebug`.
   Эталонов сейчас нет, поэтому тесты в любом случае не прошли бы.
4. Проверить, что `./gradlew verifyPaparazziDebug` падает при изменении
   компонента — иначе проверка бесполезна.

До выполнения пункта 3 задача M1 «🧪 Snapshot-тесты базовых компонентов»
остаётся открытой: тест без эталона ничего не проверяет.
