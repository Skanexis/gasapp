# Проверка iOS-версии на Mac

Как проверить iOS-часть GasApp на чужом Mac за один запуск и получить
**все** ошибки сразу — одним архивом, который можно отправить разработчику.

## ⚠️ Что сейчас умеет iOS-версия

Честно, чтобы не было разочарования: iOS-приложение — пока **прототип
интерфейса**. Экраны (вход, PIN, список чатов, чат) свёрстаны, но данные
в них заглушены, к серверу они не подключены, и этот код **ещё ни разу не
компилировался** — на Windows собрать iOS нельзя. Переписываться
с Android-телефонами с iPhone пока не получится.

Проверка на Mac отвечает на вопросы, которые без Mac не решить:

1. Собирается ли ядро (Rust) под iOS и генерируются ли биндинги Swift.
2. Компилируется ли Swift-код, и если нет — **полный список ошибок**.
3. Запускается ли приложение в симуляторе, вызывает ли ядро, не падает ли.
4. Как выглядит каждый экран (снимки).

По отчёту исправляются все ошибки за один проход, затем — следующий
запуск на Mac.

---

## Часть 1. Подготовить архив (на вашем ПК с Windows)

🪟 PowerShell, папка проекта. Сначала закоммитьте изменения: в архив
попадает только то, что в git.

```powershell
cd C:\Users\be4ho\Desktop\WORK\AEGIS
git log -1 --oneline | Set-Content -Encoding utf8 "$env:TEMP\COMMIT.txt"
git archive --format=zip --prefix=gasapp/ --add-file="$env:TEMP\COMMIT.txt" -o "$HOME\Desktop\gasapp-mac.zip" HEAD
```

На рабочем столе появится `gasapp-mac.zip` (несколько десятков МБ).
Передайте его другу: флешка, AirDrop с телефона, облако.

🔐 В архиве нет секретов: ключи и пароли лежат на вашей флешке и в
Bitwarden, а не в git. **Не кладите** в архив ничего с диска V: и файл
`server/deploy/bundle.conf`.

## Часть 2. На Mac (делает друг)

### Что нужно

* Mac на Apple Silicon (M1 и новее) или Intel, macOS 14 или новее.
* **Xcode** из App Store (бесплатно, около 15 ГБ) и ещё около 10 ГБ
  свободного места.
* Интернет: скрипт скачает Rust и библиотеки.
* Время: 30–60 минут, почти всё — ожидание.

### Шаг 1. Xcode

1. App Store → **Xcode** → «Загрузить».
2. Открыть Xcode один раз: согласиться с лицензией, дождаться установки
   компонентов. Если спросит про платформы — отметить **iOS**.
3. Если iOS-симулятора нет: Xcode → *Settings* → *Components* → iOS → *Get*.
4. Закрыть Xcode.

### Шаг 2. Распаковать и запустить

Двойной щелчок по `gasapp-mac.zip` в «Загрузках» → появится папка
`gasapp`. Затем открыть **Terminal** (Программы → Утилиты → Терминал)
и вставить:

```bash
sudo xcode-select -s /Applications/Xcode.app
cd ~/Downloads/gasapp
bash tools/mac-check.sh
```

* `sudo` спросит пароль от Mac (символы не видны) — это чтобы терминал
  пользовался установленным Xcode.
* Если Rust не установлен, скрипт спросит `Установить сейчас? [y/N]` —
  ответить `y`. Он ставится в домашнюю папку, без прав администратора;
  удалить потом: `rustup self uninstall`.
* Во время работы откроется **Simulator** с iPhone — приложение будет
  запускаться само на каждом экране. Ничего нажимать не нужно.

### Шаг 3. Результат

В конце скрипт печатает итог и открывает папку `mac-report`. Пример:

```text
Ядро Rust для iOS                  OK (612 с)
Swift: проверка типов              ОШИБКА — см. swift-typecheck.txt
  ошибок Swift                     7
  предупреждений Swift             3
Сборка приложения (симулятор)      ПРОПУЩЕНО — сначала исправить ошибки выше
Отчётов о падениях                 0
```

**Отправьте разработчику файл `~/Downloads/gasapp/mac-report.zip`** —
в нём всё:

| Файл | Что внутри |
|---|---|
| `SUMMARY.txt` | Итог по каждому шагу |
| `swift-errors.txt` | **Все** ошибки и предупреждения Swift сразу: `файл:строка: текст` |
| `rust-errors.txt`, `rust-ios.txt` | Ошибки сборки ядра |
| `link-errors.txt` | Ошибки компоновки (каких библиотек не хватило) |
| `screens/*.png` | Снимок каждого экрана |
| `console-*.txt`, `app-log.txt` | Вывод приложения и системный журнал |
| `crashes/` | Отчёты о падениях |
| `environment.txt` | Версии macOS, Xcode, Rust |

Проверить ещё и тесты ядра на macOS (дольше на 10–20 минут):

```bash
bash tools/mac-check.sh --rust-tests
```

### Если что-то пошло не так

| Сообщение | Что сделать |
|---|---|
| `Не найден Xcode` | Шаг 1; затем `sudo xcode-select -s /Applications/Xcode.app` |
| `Симулятор iOS: НЕТ` | Xcode → Settings → Components → iOS → Get |
| `xcrun: error: unable to find utility "simctl"` | `sudo xcode-select -s /Applications/Xcode.app` |
| Долго «висит» на ядре Rust | Это нормально: первая сборка 10–20 минут |
| `No space left on device` | Освободить 10 ГБ, удалить `gasapp/crates/target` и запустить снова |

## Часть 3. Что дальше (разработчику)

Положите `mac-report.zip` в папку проекта и попросите разобрать отчёт:
ошибки из `swift-errors.txt` исправляются все сразу, по снимкам
проверяется вёрстка. После исправлений — новый архив (часть 1) и новый
запуск на Mac.

Когда код соберётся и запустится, следующий шаг — настоящий проект Xcode
(нынешний `GasApp.xcodeproj` написан вручную и, скорее всего, не
откроется), подключение экранов к ядру и затем запуск на настоящем
iPhone (для этого нужна учётная запись Apple Developer).
