# Экраны iOS

⚠️ **Этот код никогда не компилировался.**

Написан вслепую: сборка SwiftUI требует Xcode, а он есть только
на macOS. На машине разработки её нет, поэтому неизвестно даже,
проходит ли код компиляцию — не говоря о поведении.

Чего ждать при первой сборке на Mac:

- опечатки и расхождения в именах API SwiftUI;
- `GasAppButton` и другие компоненты из `../Components/` могут иметь
  другую сигнатуру, чем предполагает этот код;
- цвета и отступы перенесены из UI kit, но не сверялись глазами
  ни на одном экране.

Что здесь **не** заглушка и переписывать не нужно:

- решения о безопасности и комментарии к ним — они совпадают
  с Android и приняты не для красоты: PIN не проверяется в UI,
  превью очищаются при уходе с экрана, отправка запрещается
  при недоступном ядре, предупреждение об аудите стоит до кнопки;
- палитра в `../Theme.swift` — значения из макета, они же
  в `android/app/src/main/res/values/colors.xml`.

Источник данных везде заглушен: подключение к ядру через UniFFI
делается вместе со сборкой на Mac — до неё нельзя проверить даже
то, что биндинги генерируются.
