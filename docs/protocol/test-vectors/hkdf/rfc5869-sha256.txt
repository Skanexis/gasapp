# Официальные тестовые векторы HKDF-SHA-256 — RFC 5869, Appendix A.
#
# Источник: https://www.rfc-editor.org/rfc/rfc5869#appendix-A
# Взяты три случая с SHA-256 (A.1–A.3). Случаи A.4–A.7 используют SHA-1
# и к GasApp не относятся: проект применяет только SHA-256 и SHA-512.
#
# Зачем эти векторы здесь. HKDF используется во всех четырёх
# криптографических модулях (pqxdh, double_ratchet, spqr, keystore) и до
# 2026-08-13 не был сверен ни с одним внешним источником. Ошибка в порядке
# аргументов salt/ikm или в трактовке пустой соли не проявилась бы ни в
# одном внутреннем тесте: обе стороны считали бы одинаково неправильно.
#
# Формат: одно поле на строку, hex без разделителей, пустое значение —
# пустая строка после двоеточия.
