# GasApp Support

Both stores require a support address that answers. This page is published
at `https://gasapp.eu/support/` and linked from the store listings and
from the app (About → Terms and documents → Support).

### Common questions

**I lost my phone. Can you restore my account?**
No. Your keys exist only on your device; we do not have them. If you made a
backup and kept its recovery key, install the app, choose "Restore" and
enter the key: your name, contacts and saved history come back. Without a
backup the account cannot be recovered.

**I did not get the email with the code.**
Check the spam folder. A new code can be requested after one minute. The
address must be one you can read; one address can hold one account.

**The first connection takes a long time.**
GasApp connects directly by default; Tor is an option. With Tor on, the
first connection takes 20–60 seconds, and up to a few minutes on networks
that block Tor. You can add a bridge or switch Tor on or off in
Settings → Privacy → Network;
the app explains what the server then sees.

**How do I delete my account?**
Settings → Privacy → Delete account. It is immediate. Details:
[Account deletion](account-deletion.md).

**Why can't I create a channel or a bot?**
That needs a premium account. Premium is granted by the server operator by
hand; nothing is sold in the app.

**Someone is harassing me.**
Block them (contact menu → Block) and report them (contact menu → Report).
New senders reach you only as a chat request you can decline.

**Is GasApp audited?**
Not yet. The source code is public and the limits of what it protects are
listed in the [Privacy Policy](../legal/privacy-policy.en.md).

### Частые вопросы

**Я потерял телефон. Вы восстановите аккаунт?**
Нет. Ключи есть только на вашем устройстве, у нас их нет. Если вы делали
резервную копию и сохранили ключ восстановления — установите приложение,
выберите «Восстановить» и введите ключ: вернутся имя, контакты и
сохранённая переписка. Без копии аккаунт не вернуть.

**Не пришло письмо с кодом.**
Проверьте «Спам». Новый код можно запросить через минуту. Адрес должен
быть тот, который вы читаете; на один адрес — один аккаунт.

**Первое подключение идёт долго.**
GasApp по умолчанию соединяется напрямую; Tor — по желанию. С Tor первое
подключение занимает 20–60 секунд, в сетях, где Tor блокируют, — до
нескольких минут. Добавить мост, включить или выключить Tor можно
в «Настройки → Приватность →
Сеть»; приложение объясняет, что тогда увидит сервер.

**Как удалить аккаунт?**
«Настройки → Приватность → Удалить аккаунт». Сразу. Подробности:
[Удаление аккаунта](account-deletion.md).

**Почему я не могу создать канал или бота?**
Нужен премиум. Его выдаёт оператор сервера вручную; в приложении ничего
не продаётся.

**Меня преследуют.**
Заблокируйте («Заблокировать» в меню собеседника) и пожалуйтесь
(«Пожаловаться»). Новые люди попадают к вам только запросом на переписку,
который можно отклонить.

**GasApp проходил аудит?**
Пока нет. Код открыт, а пределы того, что он защищает, перечислены в
[Политике конфиденциальности](../legal/privacy-policy.md).
