# Выпуск приложения: Android и iPhone (TestFlight)

Это **шаг 24** инструкции [ДЕПЛОЙ-С-НУЛЯ.md](ДЕПЛОЙ-С-НУЛЯ.md) — новая,
короткая версия. Серверы и сайт (шаги 1–23) уже работают.

| | Android | iPhone |
|---|---|---|
| Где собирается | у вас, одной командой в Ubuntu | в облаке Codemagic, одной кнопкой |
| Что вы делаете | вводите пароли | один раз настраиваете Apple, потом нажимаете кнопку |
| Результат | APK (на телефоны напрямую) и AAB (Google Play) | сборка в TestFlight → на iPhone |
| Время | первый раз ~1 час, потом 10–15 минут | 30–50 минут |

**Сохранять в Bitwarden — в самом конце**, одним списком (раздел 4).
Скрипты сами напомнят, что именно.

Адрес сервера, onion-адрес и пины для обоих приложений лежат в одном
файле — [`tools/release.conf`](../../tools/release.conf). Он уже
заполнен вашими значениями и сверен с сервером. Руками ничего вписывать
не надо.

---

## 1. Android

### 1.1. Перед запуском

1. **VeraCrypt** → контейнер подключён как **V:**.
2. **Docker Desktop** запущен: внизу слева «Engine running».
3. Docker Desktop → ⚙ **Settings** → **Resources** → **WSL integration**
   → переключатель **Ubuntu-24.04** включён → *Apply & restart*
   (один раз).

### 1.2. Одна команда

Откройте **Ubuntu** (меню «Пуск» → Ubuntu) и вставьте:

```bash
bash /mnt/c/Users/be4ho/Desktop/WORK/AEGIS/tools/release-android.sh
```

Скрипт сам, по порядку:

| | Что делает | Что спросит |
|---|---|---|
| 1 | находит флешку V: | если Ubuntu её не видит — **пароль Ubuntu** (sudo) |
| 2 | сверяет пины с флешкой и с сервером **прямо сейчас** | — |
| 3 | ключ подписи: нет — создаёт, есть — проверяет | **пароль ключа подписи** (новый — дважды) |
| 4 | ядро Rust для 4 архитектур (только если код изменился) | — |
| 5 | собирает APK и AAB | — |
| 6 | проверяет подпись, кладёт результат в `dist\android\` | — |

Любая ошибка — скрипт останавливается и **пишет причину по-русски**.
Повторный запуск продолжает с того же места, а не с начала.

> 🔴 **Пароль ключа подписи** — придумайте в Bitwarden (генератор, от 16
> знаков) и держите окно Bitwarden открытым. Сохранить запись можно в
> конце, но **не закрывайте Bitwarden до сохранения**: без этого пароля
> обновить приложение нельзя никогда.

✅ В конце — зелёная рамка «ВЫПУСК ANDROID ГОТОВ» и список, что сохранить.

Готовые файлы — в Windows: папка проекта → `dist\android\gasapp-1.0-1\`:

| Файл | Куда |
|---|---|
| `gasapp-1.0.apk` | на телефоны напрямую, на сайт |
| `gasapp-1.0-play.aab` | в Google Play Console |
| `SHA256SUMS.txt` | суммы — опубликовать рядом с APK |

### 1.3. 🔴 Проверка на двух телефонах — до публикации

Скопируйте `gasapp-1.0.apk` на **два настоящих** телефона и установите:

1. Регистрация: письмо с кодом приходит, аккаунт создаётся.
2. Сообщение с одного телефона на другой приходит.
3. Фото отправляется и открывается.
4. Таймер исчезающих сообщений: сообщение исчезает **на обоих**.
5. Настройки → Сеть → Tor → приложение подключается.
6. Политика конфиденциальности открывается.

Не подключается вообще — **не публикуйте**: пришлите текст ошибки.

### 1.4. Google Play — первая выгрузка

1. play.google.com/console → приложение → **Test and release** →
   **Internal testing** → *Create new release* → загрузить
   `gasapp-1.0-play.aab` → *Save* → *Review* → *Start rollout*.
2. Там же: **Setup** → **App integrity** → **App signing** → скопировать
   **SHA-256** из «App signing key certificate».
3. Сохранить его в файл на флешке — в **PowerShell**:

   ```powershell
   Set-Content V:\gasapp\play-app-signing-sha256.txt "ВСТАВЬТЕ_SHA-256"
   ```

4. В `tools/release.conf` увеличить `VERSION_CODE` на 1 (было `1` →
   стало `2`) и запустить команду из 1.2 ещё раз. Эту сборку и
   отправлять дальше: она знает ключ Google и не будет предупреждать
   «подпись не совпадает».

Анкеты магазина (описание, Data safety, возраст) — в
[docs/store/GOOGLE-PLAY-ПОДАЧА.md](../../docs/store/GOOGLE-PLAY-ПОДАЧА.md).

### 1.5. Следующие версии

`tools/release.conf` → `VERSION_CODE` + 1 (и при желании `VERSION_NAME`,
например `1.1`) → команда из 1.2. Всё.

## 2. iPhone: TestFlight через Codemagic

Сборка идёт в Codemagic на Mac в облаке — тот же, где проходит
проверка «iOS check». Mac у вас не нужен.

### 2.1. Один раз: Apple

1. **Apple Developer Program** — developer.apple.com/programs → *Enroll*
   (99 $ в год; для частного лица — 1–2 дня проверки). Без него
   TestFlight недоступен.
2. **Team ID** — developer.apple.com → *Account* → *Membership details* →
   «Team ID» (10 символов). Скопируйте в блокнот.
3. **Идентификатор приложения** — developer.apple.com → *Certificates,
   IDs & Profiles* → **Identifiers** → «+» → *App IDs* → *App* →
   * Description: `GasApp`
   * Bundle ID: **Explicit** → `org.gasapp.messenger`
   * отметить **Push Notifications** и **Data Protection** (Complete
     Protection)
   * *Continue* → *Register*.
4. **Приложение в App Store Connect** — appstoreconnect.apple.com →
   **Apps** → «+» → *New App*:
   * Platform **iOS**, Name **GasApp** (занято — `GasApp Messenger`),
     язык Russian, Bundle ID `org.gasapp.messenger`, SKU `gasapp-ios`.
5. **Ключ API** — appstoreconnect.apple.com → **Users and Access** →
   **Integrations** → **App Store Connect API** → *Team Keys* → «+»:
   * Name `Codemagic`, Access **Admin** (нужно для подписи в облаке);
   * **Download** — файл `AuthKey_XXXXXXXXXX.p8` скачивается **один
     раз**: сразу перенесите его на флешку, в `V:\gasapp\apple\`;
   * скопируйте **Key ID** (в строке ключа) и **Issuer ID** (над
     таблицей).

### 2.2. Один раз: Codemagic

codemagic.io → **Teams** → ваша команда → **Global variables and
secrets** → группа (Variable group) **`app_store`** — добавить четыре
переменные, у каждой галочка **Secure**:

| Имя | Значение |
|---|---|
| `APPLE_TEAM_ID` | Team ID из 2.1.2 |
| `ASC_KEY_ID` | Key ID из 2.1.5 |
| `ASC_ISSUER_ID` | Issuer ID из 2.1.5 |
| `ASC_KEY_P8` | файл `AuthKey_….p8`, открытый в Блокноте, — **весь текст** со строками `-----BEGIN PRIVATE KEY-----` и `-----END PRIVATE KEY-----` |

> ⚠️ Имя группы — ровно `app_store`: по нему сборка находит секреты.

### 2.3. Каждый выпуск: одна кнопка

codemagic.io → приложение → **Start new build** → ветка `gasapp` →
workflow **iOS → TestFlight** → *Start new build*.

✅ Через 30–50 минут сборка зелёная, последняя строка журнала —
«Выгружено». Ещё через 10–30 минут она появится в App Store Connect →
**TestFlight**.

❌ Красная — откройте упавший шаг: первая строка объясняет причину
(нет переменной, расходятся настройки, ошибка подписи). Пришлите её.

### 2.4. Первый раз в TestFlight

App Store Connect → приложение → **TestFlight**:

1. У сборки «Missing Compliance» → *Manage* → ответы:
   * Uses encryption — **Yes**;
   * proprietary / non-standard algorithms — **No** (только стандартные);
   * French encryption declaration — приложение во Франции **не
     распространяется** (решение в [docs/store/app-store.md](../../docs/store/app-store.md)).
2. **Internal Testing** → «+» → группа `Я` → добавить свой Apple ID.

### 2.5. На iPhone

App Store → установить **TestFlight** → письмо-приглашение → *Accept*
→ *Install*. Новые сборки приходят туда же (кнопка *Update*).

Проверка — те же 6 пунктов, что в 1.3, плюс сообщение **между iPhone и
Android**.

> ℹ️ Уведомления на iPhone придут, только когда на сервере настроен
> ключ APNs ([docs/ops/push.md](../../docs/ops/push.md)). Без него
> приложение работает, просто новые сообщения видны при открытии.

## 3. Если поменялся сервер

Сменили ключ TLS (ротация пинов), onion-адрес или домен:

1. Исправить [`tools/release.conf`](../../tools/release.conf).
2. В Ubuntu: `python3 /mnt/c/Users/be4ho/Desktop/WORK/AEGIS/tools/apply-release-config.py`
   — перепишет настройки обоих приложений.
3. Закоммитить и собрать обе платформы заново.

Сборка с расходящимися настройками не пройдёт: и скрипт Android, и
Codemagic это проверяют.

## 4. В конце: сохранить в Bitwarden — всё сразу

Когда оба выпуска собраны и проверены:

| Что | Куда |
|---|---|
| Пароль ключа подписи Android | запись «Android: пароль ключа подписи» |
| Отпечаток ключа подписи (печатает скрипт, файл `dist\android\…\signing-cert-sha256.txt`) | заметка той же записи |
| Team ID, Key ID, Issuer ID Apple | запись «Apple: App Store Connect API» |
| Файл `AuthKey_….p8` | вложение той же записи (он же лежит в `V:\gasapp\apple\`) |
| SHA-256 ключа Google Play | заметка записи «Google Play» |
| **Флешка изменилась** (новый `gasapp-release.jks`, `apple\`, `play-app-signing-sha256.txt`) | отключите V: в VeraCrypt → обновите вложение-контейнер (шаг 2.4 основной инструкции) |
